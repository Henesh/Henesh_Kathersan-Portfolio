Featured Project

SmartSave: Agentic Financial Advisor

An AI-powered personal finance assistant designed to help Malaysian university students track expenses, understand spending behaviour, and receive personalised saving recommendations — all through Telegram and a React dashboard.

Dashboard Overview — Spending Analytics
React + Recharts Dashboard — Real-time spending visualisation with category breakdown, budget tracking, and AI advice panel.
Telegram Bot — Expense Logging
Telegram Bot Interface — Users log expenses naturally via text or receipt images. The bot confirms and stores transactions instantly.
OCR Processing — Receipt Understanding
EasyOCR Pipeline — Extracts merchant, total amount, and transaction details from receipt images with Malaysian-context categorisation.

The Problem

  • Manual expense tracking is time-consuming and often abandoned.
  • Students struggle to understand where their money is spent.
  • Receipts are stored without being analysed.
  • Existing finance apps require too much manual input.
  • Lack of simple, actionable recommendations based on actual habits.
  • Privacy concerns with cloud-based financial applications.

The Solution

  • Low-friction tracking — log expenses via Telegram messages or receipt images.
  • AI-powered analysis — OCR + NLP categorisation engine tailored for Malaysian spending.
  • Local LLM reasoning — Mistral 7B via Ollama generates human-readable financial advice.
  • Privacy-first — deterministic calculations + local AI keeps data secure.
  • Real-time dashboard — React + Recharts visualises spending patterns and tracks budgets.
