02 / Final Year Project

SmartSave turns spending into action.

A multi-modal AI financial assistant that lets students log expenses through Telegram, automatically process receipts and receive grounded saving recommendations.

THE PROBLEM

Budgeting is easy to abandon.

Manual expense entry creates friction. Student spending is spread across cash, e-wallets and bank receipts, making consistent tracking difficult.

THE PRODUCT

Make tracking feel effortless.

Send text, a receipt photo or PDF to Telegram. SmartSave routes the input, extracts the data, categorizes it and turns it into useful financial guidance.

CareerSeer

An intelligent job-matching platform built with a team using Flask, React and NLP. My focus was the Resume Analyzer module — parsing unstructured resumes (PDF/DOCX) into clean, structured profile data: education history, skill sets, work experience and contact details. That structured profile feeds the platform's career recommendation engine, which scores and ranks job postings against the candidate's extracted skills, and powers the applicant's dashboard view. 02

Movie Genre Classification

Compares RNN, LSTM and GRU architectures for predicting a movie's genre from its plot description. Plot text is cleaned, tokenized and vectorized before being fed into each recurrent architecture; all three are trained under the same conditions so their ability to capture sequential context and long-range dependencies in narrative text can be compared head-to-head, with results benchmarked to identify the strongest performer. Accuracy and F1 are tracked per genre rather than only overall, since genre labels are unevenly represented and a model can look strong on average while quietly failing on the rarer categories.

04

Trash Type Detection

A CNN-based classifier that identifies waste type from images to support smarter recycling and automated sorting. Built in MATLAB using ResNet18 with transfer learning: the pretrained network's convolutional base is kept and its final layers are retrained on a labeled waste-image dataset. Performance is evaluated using accuracy, a confusion matrix, precision, recall and F1-score to check the model isn't just accurate overall but reliable across every waste category — since a sorting system that fails silently on one material type is worse than one that's evenly mediocre.

05

Clinic Appointment System

Built entirely in C++, the system organizes patients, doctors and appointment slots into structured records. Every new booking is checked against existing appointments to detect and prevent double-booking before it's confirmed, and basic authentication keeps patient and staff records separated by role. Core data operations follow a CRUD pattern (create, read, update, delete) so records stay consistent as appointments are booked, rescheduled or cancelled, with doctors, front-desk staff and admins each scoped to only the views and actions relevant to their role.
