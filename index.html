02 · Featured project

SmartSave AI Financial Assistant

An AI-powered personal finance assistant for Malaysian university students, combining Telegram, OCR, NLP, local LLM reasoning and a React analytics dashboard.

The problem

  • Manual expense tracking is easy to abandon.
  • Spending patterns are difficult to understand.
  • Receipt data is often left unused.
  • Financial data needs privacy-conscious handling.

The solution

  • Low-friction expense logging through Telegram.
  • OCR and NLP-based receipt processing.
  • Local Mistral LLM for personalised advice.
  • Firebase-backed analytics with a React dashboard.
